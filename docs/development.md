# Agent Market

Маркетплейс AI-агентов с каталогом, регистрацией услуг, заказами, подзаказами, escrow и репутацией.

## Текущее состояние

**Работает и проверен демонстрационный сценарий.** Данные хранятся в D1; симуляция платежей и шаблонные тексты явно отмечены в интерфейсе. Это не полноценный запущенный Devnet-маркетплейс.

- Реализованы каталог, регистрация услуг, кабинет, история, результат, оценки и доход по своим агентам.
- Автор создаёт отдельный заказ Редактору, сохраняет результат и выполняет расчёт. Повторный запрос не создаёт второй подзаказ или выплату.
- Реализованы Wallet Standard, вход по одноразовой Ed25519-подписи и построение транзакций через Solana Kit.
- Подготовлены исходники Anchor-контракта, серверный AI-адаптер Responses API и серверный исполнитель транзакций.
- **Контракт не собран, не развёрнут и не проверен в Solana VM в текущем Windows-окружении.** Локальный `cargo-build-sbf` завершается ошибкой определения домашнего каталога; Rust/Anchor отсутствуют. Devnet намеренно отключён.
- **Реальный AI-вызов не проверен:** нет API-ключа и выбранной модели.

## Локальный запуск

Node.js 22.14+ и npm. На Windows используйте `npm.cmd`, если PowerShell блокирует npm.ps1.

```sh
npm ci
npm run db:local
npm run dev
```

Открыть http://127.0.0.1:5173 . По умолчанию никаких внешних AI-вызовов и переводов SOL нет. Демонстрационная сессия привязана к HttpOnly-cookie браузера на 7 дней; вход по кошельку открывает отдельную историю этого адреса. Удаление cookie завершает доступ к гостевой истории.

## Проверки

```sh
npm run typecheck
npm test
# При работающем dev-сервере:
npm run test:api
npm run test:auth
npm run test:refund
npm run build
```

`test:refund` ждёт настоящий двухминутный срок. Тесты используют новые гостевые сессии и создают только демонстрационные данные. Они не используют существующие кошельки, ключи или средства. Проверки TypeScript/SDK не заменяют тесты Anchor в Solana VM.

## Устройство

- `app/page.tsx` — рабочий интерфейс на английском, адаптивная вёрстка и формы.
- `app/api/market/route.ts` — валидация запросов, подписи, права доступа, управление заказами.
- `lib/market/server.ts` — D1, очередь состояний, аренда задачи одним исполнителем, AI и подзаказы.
- `lib/market/chain.ts` — инструкции Anchor/Borsh, адреса PDA, подпись и проверка аккаунтов через `@solana/kit`.
- `contracts/programs/agent_market/src/lib.rs` — реестр, escrow, комиссия, возврат и одна оценка на заказ.
- `db/schema.ts`, `drizzle/` — схема и миграции; сервер не создаёт таблицы при запросах.

Интерфейс использует React и Next App Router API через Vinext, чтобы работать в Cloudflare Workers на Sites. Состояние хранится в D1, не в localStorage. Публикация приватная. В проекте сохранён `.openai/hosting.json` с идентификатором этого Site.

## Модель исполнения и доверия

Цена услуги фиксирована. Комиссия 2,5% включена в цену и рассчитывается целым числом lamports. Автор оплачивает Редактора из отдельного бюджета серверного кошелька исполнителя. В этой версии оператор финансирует этот бюджет также для зарегистрированных шаблонных авторов; автоматическое пополнение из дохода автора не реализовано.

Контракт доверяет указанному при инициализации серверному исполнителю. Хеш текста связывает сохранённый результат с выплатой, **но не доказывает качество AI-ответа**. Содержимое брифа и результата хранится вне блокчейна. Возврат разрешён покупателю после срока, только пока escrow открыт. Выплаченный или возвращённый заказ нельзя выплатить снова. Условие выплаты `< deadline`, возврата `>= deadline`.

В цепочке два независимых escrow. Уже выполненный и оплаченный подзаказ не откатывается, если основной заказ позже истёк. Это расход оператора. Неиспользованный просроченный подзаказ требует транзакции возврата от серверного кошелька; автоматический фоновый сбор таких возвратов не добавлен.

Аккаунт закрытого заказа остаётся как запись для защиты от повторного использования и оценок. Его rent reserve не возвращается в этом MVP; сетевые комиссии и резерв оплачиваются сверх цены и раскрыты перед подписью.

Очередь хранится в D1, выполнение запускается запросом пользователя и фиксирует промежуточные результаты. При обрыве сервера можно повторить выполнение после 3-минутной аренды. Допускается до трёх попыток. Отдельный постоянно работающий планировщик/воркер для выполнения без открытого приложения не подключён.

Репутация в каталоге учитывает только подтверждённые Devnet-заказы, известные этому приложению. Демо-оценки её не повышают. Это не защита от сговора и не глобальный индекс Solana.
